How these were found (5 independent channels)
1. Dorked search
342 queries across Startpage / Ecosia / Brave: CLI snippets (claude mcp add, mcp-remote), config shapes, endpoint shapes, and loose auth phrasing ("a browser window will open", "connect your account", "approve the connection") — not just the word oauth.
2. Official page mining
1,594 vendor/doc pages fetched and parsed for endpoint URLs plus the sentence around them, kept as citable evidence.
3. Crawl-corpus census
urlscan.io queried 67 ways (domain:mcp.*, /mcp paths, 401 pages, oauth URLs) for hostnames seen in the wild.
4. DNS census
mcp.<domain> resolved over DNS-over-HTTPS for the top 1,000,000 domains on the internet — 189,530 live hostnames found and screened.
5. Live verification
Every candidate got a real MCP initialize POST, then /.well-known/oauth-protected-resource and authorization-server metadata discovery to extract authorize/token/registration endpoints and scopes.
Tier A = answered MCP protocol or published OAuth metadata for the endpoint  ·  Tier B = auth wall with a Bearer challenge, MCP-shaped but not fully confirmable without credentials  ·  hosts behind a generic non-MCP auth wall were dropped, not counted.
