Method, and what this cannot see

Why probing rather than 3,186 searches. A keyword search per domain returns whatever a search index happens to hold; asking the domain itself returns ground truth. Every confirmation here is a response from infrastructure the vendor controls. The earlier search-only pass found 30 vendors; direct probing found 365, including Airtable, MongoDB, Vimeo, Upwork, Mapbox, Semrush, Instacart, GoCardless and Evernote, none of which surfaced through search.
  • Resolution: DNS-over-HTTPS (Cloudflare, Google fallback) for the root plus mcp., api. and docs., with a wildcard canary so wildcard DNS could not fake a hit. The local resolver was discarded after it produced ~1,400 false negatives.
  • Probing: a real JSON-RPC initialize POST across ten path patterns (/mcp, /v1/mcp, /api/mcp, /sse, …), plus /.well-known/oauth-protected-resource.
  • False-positive control: HTML, captcha and CDN interstitials can never establish a tier. For ambiguous 401/403 answers a nonsense control path was probed on the same host; if it answered identically the signal was discarded — this removed 95 of 106 candidates.
  • Blind spot: servers on hosts no pattern would guess (AWS api.aws, Google *.googleapis.com) are only found via documentation; those were probed explicitly and verified. Comparable undocumented hosts elsewhere would be missed.
  • Tenant-scoped servers (Databricks per-workspace, Shopify per-shop) have no single public endpoint; they are recorded against the vendor domain.
  • 185 domains answered nothing on any probe even after a retry with longer timeouts — firewalled, parked or non-HTTP. They are reported as unreachable rather than negative.
  • Search sweep: after probing, all 2,816 unconfirmed domains got an individual web search (3,034 queries). Every first-party page it surfaced was then fetched and mined for endpoint URLs, which were probed in turn. That is how Meta, Robinhood, Spotify, Adobe, Cloudinary, CoinGecko, Twilio, Greenhouse and Indeed were found — their servers sit on hosts like targetmcp.adobe.io and agent.robinhood.com that no subdomain guess would reach.
  • Auth model: taken from each endpoint's own OAuth metadata chain — protected-resource metadata, then authorization-server metadata — recording whether Dynamic Client Registration is open and whether PKCE is advertised. Endpoints that only accept a static API key are labelled as such, not counted as OAuth.
  • Docs column links first-party pages surfaced by search; a missing link means the endpoint was verified live but no doc page surfaced, not that none exists.
